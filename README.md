# Andréa Cocolichio | Alquimista e Terapeuta Integrativa

Site da Andréa Cocolichio: Alquimia Floral Personalizada, Sagrado Feminino, Medicina do Cacau e Cone, em Porto Alegre e online.

É um único `index.html`, com as fotos embutidas, e não precisa de build.

## Publicar na Vercel
Importe o repositório, escolha Framework Preset "Other" e deixe o build command e o output directory vazios.

## Antes de publicar
- Atualize a data do próximo encontro Mulheres de Gaia (hoje: 12 de novembro).
- Tire a linha `<meta name="robots" content="noindex">` depois da aprovação.
